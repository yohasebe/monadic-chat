# 匿名化

## 概要

**匿名化**は、選んだ語（人名、組織名、住所など）を、会話が AI プロバイダに送る文の中で `<<PERSON_1>>` のようなプレースホルダーに置き換えます。返答では語が元に戻るので、会話はふだんどおりに読み書きできます。

伏せる語の一覧は会話ごとに持ちます。名前はこのコンピューターで動く Privacy コンテナが探し、どの語を伏せるかは利用者が決めます。

## 語を伏せる :id=hiding-words

1. メッセージを書いてから、メッセージ欄の横の **匿名化** をクリックします。
2. パネル **この会話で伏せる語** に、見つかった名前を強調したメッセージと、名前と種類の一覧が表示されます。伏せない語は横の **×**（**伏せない**）をクリックします。種類を変えるときは、その語のメニューで選びます。
3. 見つからなかった語を足すときは、パネルの本文でその語を選択し、種類を選んで **選択した語を伏せる** をクリックします。
4. **これらの語を伏せる** をクリックしてから、メッセージを送ります。

語は会話のどこに現れても伏せられます。メッセージ欄の横の表示（**{n} 語を伏せています**）をクリックすると、パネルをもう一度開き、語の種類を変えたり、伏せるのをやめたりできます。伏せないことにした語は **伏せない語：** に並び、候補として再び示されません。クリックすると（**この語を再び候補にする**）候補に戻ります。

変更は、それ以降に会話が送るものから反映されます。

!> **匿名化の対象。** アプリが会話のために送る文だけです。そのまま送られる画像、画面の内容、ファイル、声（音声入力は録音をそのまま文字起こしのサービスに送ります）、一覧にない名前、語を伏せる前に送ったものは対象外です。会話の履歴、ログ、**Restored** の書き出しには元の語が残ります。匿名化は、一覧の語の代わりにプレースホルダーをプロバイダに見せるものであり、会話を共有しても安全にするものではありません。

## 語が伏せられる場所

語は、会話が送る次のものの中で伏せられます。

- 会話自身のモデルへの要求（それまでのメッセージとツールの結果を含む）
- セカンドオピニオン、**Verify**、AI User の提案、Session Context の抽出、タイトルの提案
- ナレッジベースの検索結果（モデルに渡るとき）
- 読み上げる文（伏せた語は「PERSON 1」のように種類と番号で読まれます）

[作業画面](../basic-usage/web-interface.md#work-screen)について AI に伝える内容と、AI がそこで見る文は、伏せずに確認します。伏せた語が含まれていれば送りません。

要求は送る直前にもう一度確かめます。置き換えない部分（システムプロンプトやツールの定義など）に伏せた語が残っている要求は送らず、エラーで知らせます。伏せた語を含むシステムメッセージは、書いた時点で受け付けません。

語の一覧を読めない会話（サーバーを再起動した後など）は、[会話の履歴](../basic-usage/web-interface.md#chat-history-panel)から開き直すまで何も送りません。

## 音声と Live Conversation

語を伏せている会話でも音声入力は使えますが、声そのものは伏せられません。Live Conversation（speech-to-speech）は会話をそのまま送るので、語を伏せている会話では使えません。

## ナレッジベース :id=knowledge-base

語を伏せている会話は、ナレッジベースに保存できません。ナレッジベースに語が残り、別の会話の検索からその語が送られるためです。このような会話を残すときは **Export** を使います。

## 書き出しと読み込み :id=export

**Export** ボタンで開くダイアログには、互いに独立した 2 つの選択があります。

- **暗号化**：指定したパスフレーズでファイルを AES-256-GCM（Argon2id 鍵導出）で暗号化します。パスフレーズは 8 文字以上で、確認欄と一致する必要があります。
- **内容**（語を伏せている会話で表示）：**Restored** は元の語と会話の語の一覧を含めて書き出すので、読み込んだ会話でも語を伏せ続けます。**Masked** はファイルのどこでも伏せた語をプレースホルダーに置き換えて書き出し、元の語も一覧も含めません。

語を伏せている会話では、ダイアログは **Masked** を選んだ状態で開きます。暗号化せずに **Restored** を選ぶと警告が出て、ファイル名の末尾に `-PRIVATE` が付きます。

書き出したファイルは **Import** で開きます（暗号化したファイルはパスフレーズも入力します）。以前の版のファイルで伏せる語の印があるものは、その語を会話の一覧に読み込みます。何語かを画面が知らせるので、パネルで確認できます。新しいメッセージでは `⟦` と `⟧` は普通の文字です。

## ドキュメント DB のエクスポート / インポート（Actions メニュー） :id=document-db-export-import

**Actions → Export Document DB** と **Actions → Import Document DB** メニューは qdrant ボリューム全体（ナレッジベースに保存したすべての会話・PDF・その他の Knowledge Base エントリ）を対象とします。[会話の履歴](../basic-usage/web-interface.md#chat-history-panel)は含まれません。両メニューとも、実行前に確認ダイアログを表示します。

エクスポートでは次の 2 つから選べます:

- **Encrypt and Export**（デフォルト）: パスフレーズを尋ね、tarball を AES-256-GCM（PBKDF2-SHA256, 600 000 回反復）でエクスポートごとのランダムソルトを使って暗号化し、`monadic-qdrant.tar.gz.enc` を共有フォルダに書き出します。暗号化に成功すると平文の tarball は削除されます。
- **Export Plain**: 暗号化せずに tarball を直接書き出します。ダイアログでは、ナレッジベースに保存した会話と PDF がすべて平文で含まれることを警告します。

インポートはファイル拡張子を自動判別します: `.tar.gz` はそのまま展開され、`.tar.gz.enc` ではパスフレーズを尋ねて一時平文ファイルに復号した後 qdrant ボリュームのインポートを実行し、最後に一時ファイルを削除します。パスフレーズが間違っていたり改ざんされている場合は復号に失敗し（tarball は中途半端に展開されません）、qdrant ボリュームには手が触れられません。

暗号化フォーマット: `[magic 'MQDB'] [version 0x01] [salt 16] [iv 12] [ciphertext] [authTag 16]`。ストリーミング処理可能な構造のため、複数 GB のボリュームでもメモリに乗せきる必要はありません。

## 名前を探す :id=finding-names

名前は、このコンピューターで動く Privacy コンテナ（Microsoft Presidio と spaCy のモデル）が探します。このコンテナは Monadic Chat と一緒に起動します。動いていないときは **匿名化** が起動し、名前を探す機能が起動中だと知らせます。少し待ってからもう一度試してください。パネルで語を自分で選ぶことはいつでもできます。

メッセージは、サイドバーの会話の言語で読みます。**Automatic** のときは、判定した言語で読みます。英語は常に使えます。他の言語で名前を探すには、**Actions → Install Options** を開き、**Name Finder — Additional Languages** で言語（ドイツ語、スペイン語、フランス語、イタリア語、日本語、オランダ語、ポルトガル語、中国語）をオンにします。変更は保存したときに反映され、リビルドは要りません。

すべての名前が見つかるわけではありません。日本語では、言語モデルが見つけるものに加えて、敬称（さん、様、氏、先生、くん、君、ちゃん、殿）の付いた 2〜12 文字の漢字またはカタカナの名前をまるごと見つけます。ひらがなの名前、敬称のない名前、珍しい名前は見つからないことがあります。そのような語は自分で足してください。

## 設定リファレンス

`~/monadic/config/env` に保存される設定：

| 変数 | 値 | デフォルト | 説明 |
|---|---|---|---|
| `PRIVACY_FILTER` | `true` / `false` | `true` | `false` にすると Privacy コンテナをダウンロードも起動もしません。名前は自動では見つからなくなりますが、語を自分で選ぶことはできます。 |
| `PRIVACY_LANGS` | 言語コードのカンマ区切り | `en` | Privacy コンテナが読み込む言語。**Actions → Install Options** で保存すると英語は自動で加わります。ファイルを直接編集するときは `en` を含めてください。使えるコード：`en`、`de`、`es`、`fr`、`it`、`ja`、`nl`、`pt`、`zh`。 |
| `PRIVACY_DEV_PORT` | ポート番号 | `8001` | 開発モードでだけ使います。ホストから Privacy コンテナに接続するためのポートです。 |

ファイルで `PRIVACY_FILTER` か `PRIVACY_LANGS` を直接変えたときは、Monadic Chat を再起動してください。

## 自作アプリ

アプリの MDSL にある `privacy do` ブロックは効果がなく、アプリを読み込むときにサーバーが警告を出します。削除してください。`features` ブロックに `library_save false` と `library_search false` がないアプリは、ナレッジベースに保存し、検索できます。
