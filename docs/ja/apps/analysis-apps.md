# Web・メディア分析アプリ

外部コンテンツを分析するアプリです。スクリーンショット付きのインタラクティブなWebブラウジングと、動画コンテンツの内容説明に対応します。

## Web Insight :id=web-insight

スクリーンショット付きでWebコンテンツを閲覧・キャプチャするアプリケーションです。URLを指定するとAIがページをビューポートサイズのスクリーンショットとして撮影します。インタラクション（クリック、フォーム入力、ナビゲーション）が必要な場合は、AIがヘッドレスブラウザセッションを開き、各アクション後にスクリーンショットを返します。

**主な機能:**
- **スクリーンショット撮影**: ページ全体を自動スクロールしながら複数のビューポートサイズの画像として撮影
- **インタラクティブ操作**: AIがヘッドレスChromeブラウザを操作し、リンクのクリック、フォーム入力、スクロールなどを実行。各アクション後にスクリーンショットで結果を確認
- **カスタマイズ可能なビューポート**: デスクトップ、タブレット、モバイル、印刷用のプリセット
- **確認なしの操作**：AI は、操作のたびに確認を求めずに実行します

**インタラクティブブラウザセッション:**

AIにページ操作を依頼すると、Seleniumコンテナ内でヘッドレスブラウザセッションが開始されます。AIはリンクのクリック、テキスト入力、ページのスクロール、ページ間の移動など、1セッションあたり最大20アクションを実行できます。各アクション後にAIがスクリーンショットを受け取り、結果を確認します。

指示が曖昧な場合（例：「検索ボタンをクリックして」と言ったが候補が複数ある場合）、AIは候補要素に番号付きラベルを付けたスクリーンショットを表示し、どれを選ぶか確認します。

AI が操作しているブラウザを見たいときは、画面のある（ヘッドレスでない）ブラウザを使うよう AI に頼み、メニューバーの **Open > Open noVNC** で noVNC を開くか、ブラウザーで `http://localhost:7900` を開いてください。

**使用例:**
- `"https://github.com のスクリーンショットを撮って"` - 複数のスクリーンショットを撮影
- `"https://example.com を開いてAboutリンクをクリックして"` - インタラクティブ操作
- `"Googleで'monadic chat'を検索して"` - AIがページを操作
- `"https://example.com のモバイル版スクリーンショットを撮って"` - モバイルビューポートプリセットを使用

Web Insightの対応プロバイダーは[モデル対応状況の表](../basic-usage/basic-apps.md#app-availability)を参照してください。


## Video Describer

![Video Describer app icon](../assets/icons/video-describer.png ':size=40')

動画の内容を詳しく説明するアプリです。動画からフレームと音声を取り出し、映っているものと聞こえるものを AI が説明します。Video Describer は OpenAI、Google Gemini、xAI（Grok）で使えます。

**使い方**：入力欄の下の添付のボタン（モデルによって `Attach file` または `Image`）で動画を添付するか、動画のファイルを共有フォルダに置いて名前を伝えます。調べる 1 秒あたりのフレーム数（fps）も伝えてください。動画は、文章を付けても付けなくても送れます。回答の中で動画を再生できます。

**動画のファイル**：MP4、M4V、MOV、WebM、MKV、AVI、MPEG で、映像のトラックがあり、長さが 50 分以内、縦横がそれぞれ 4096 ピクセル以内のものです。形式はファイルの拡張子と一致している必要があります。条件を満たさないファイルは処理されず、理由が表示されます。

**フレーム**：フレームは、プロバイダーが 1 回の要求で受け付ける枚数の範囲で、動画の場面と目に見える変化を網羅するように選ばれ、説明の中で出来事の起きた時刻が示されます。選ばれたフレームの間の短い出来事は、拾えないことがあります。10 分を超える動画では、詳しい解析を頼むと、動画を 10 分以内のパートに分けて説明するので、短い出来事を拾いやすくなります。時間と料金は多くかかります。説明できなかったパートは、そのように示されます。

**音声**：発話はアプリのプロバイダーの音声認識で文字起こしされ、文字起こしの各行の先頭に動画の中の時刻が付きます（例：`[01:02–01:06]`）。説明では、言われたことと映っているものが結び付けられます。文字起こしの全文は別の節に表示されます。発話以外の音（音楽、拍手、雑音）は文字起こしされません。xAI Grok では、日本語の中の英語のように言語が混ざる発話が、別の文字で書かれたり訳されたりすることがあります。そのような録音には OpenAI か Google Gemini を使ってください。文字起こしは字幕のファイル（WebVTT と SRT）と一緒に会話のフォルダ（共有フォルダの `conversations/`）に保存され、回答の動画は字幕付きで再生されます。映像が音声より遅れて始まる動画では、文字起こしの時刻がプレーヤーの時刻とその分だけ違い、回答にその旨が示されます。

詳しい解析と時刻付きの文字起こしには、最新の Python コンテナが必要です。コンテナがアプリより古いときは、**Actions → Build Python Container** で作り直すよう回答で案内します。
