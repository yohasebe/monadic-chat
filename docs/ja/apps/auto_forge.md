# Auto Forge

Auto Forge は、説明をもとに、1 つのファイルでできた Web アプリケーションやコマンドラインのツールを作るアプリです。会話の相手のモデルが作業を計画してやり取りをし、同じプロバイダーのコード生成モデルがコードを書きます。

Auto Forge は OpenAI、Anthropic（Claude）、xAI（Grok）で使えます。使うプロバイダーの API キーが必要です。

## 作れるもの

- **Web アプリケーション**：CSS と JavaScript を中に含む 1 つの HTML ファイルです。サーバーなしにブラウザーで動き、外部から何も読み込みません
- **コマンドラインのツール**：Python、Ruby、Node.js など、目的に合った言語の単独のスクリプトです。頼めば、README、設定のひな形、依存関係の一覧（`requirements.txt` や `Gemfile` など）も書きます

Web アプリケーションの例：電卓、ブラウザーにデータを保存する ToDo リスト、タイマー、お絵かきのキャンバス、神経衰弱のゲーム、Markdown のエディター、配色の生成。コマンドラインのツールの例：データの変換（CSV、JSON、XML）、バックアップの補助、ログの分析、ファイルの整理。

## 使い方

1. 使いたいプロバイダーの **Auto Forge** を選び、作りたいもの（名前、何をするものか、機能）を説明します
2. OpenAI と xAI では、Auto Forge がまず手順の計画を示し、承認を待ちます。始める前に変更を頼めます
3. Auto Forge がアプリケーションを作ります。複雑なアプリケーションでは、コードの生成に数分かかることがあります。その間、進み具合がチャットに表示されます
4. 改善や機能の追加を頼みます

### 変更と作り直し

アプリケーションを変えるときは、同じアプリケーションの名前で変更を頼みます。Auto Forge は、そのプロジェクトの最新の版を更新します。同じ名前で一から作り直すときは、作り直しを頼みます。新しいプロジェクトのフォルダが作られます。

作ったプロジェクトを見るときは、一覧を出すよう Auto Forge に頼みます。

## Web アプリケーションのテスト

Auto Forge は、作った Web アプリケーションを Selenium コンテナの Chrome で開き、次のことを報告できます。
- JavaScript のエラーとコンソールの警告
- フォーム、ボタンなどの操作できる要素を試した結果
- 読み込み、DOM の準備、描画にかかった時間
- ページのスクリーンショット

OpenAI と xAI では、この確認は Web アプリケーションを作る作業の中で行われます。Claude では、頼んだときに行われます。

## プロジェクトの保存場所

プロジェクトは `~/monadic/data/auto_forge/` に、プロジェクトごとのフォルダとして保存されます。フォルダの名前は、プロジェクトの名前と日時です。

```text
auto_forge/
├── TodoApp_20260127_143022/
│   └── index.html
├── Calculator_20260127_151234/
│   └── index.html
├── runtimes-lister_20260928_234449/
│   ├── runtimes_lister.py
│   └── README.md
└── ...
```

プロジェクトの名前には、どの言語の文字も使えます。

## ヒント

1. 欲しい機能を詳しく説明する
2. 簡単なところから始めて、機能を少しずつ加える
3. それぞれのプロジェクトに、内容がわかる名前を付ける

## 困ったとき

- **ファイルがまだ作られない**：複雑なアプリケーションでは、コードの生成に数分かかることがあります。チャットの進み具合の表示が終わるまで待ってください
- **「Selenium container is not running」**：Selenium コンテナは Monadic Chat と一緒に起動します。起動時のエラーがコンソールに出ていないか確かめ、Monadic Chat を起動し直してください
- **「Project not found」**：プロジェクトの一覧を出すよう Auto Forge に頼み、正確なプロジェクトの名前を使ってください
