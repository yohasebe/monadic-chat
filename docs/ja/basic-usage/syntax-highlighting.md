# シンタックス・ハイライト

Monadic Chat は、チャット内のコードブロックの構文を [highlight.js](https://highlightjs.org/) で色分けします。幅広いプログラミング言語に対応しています。

## 設定

- **テーマ選択**: Settings → General → Syntax Highlighting Theme から好みのテーマを選択
- **デフォルトテーマ**: `github-light`（良好な可読性を提供するライトテーマ）
- **言語**: 言語はコードブロックの印から取ります（例：` ```python`）。印がないときは判定します
- **テーマの永続化**: テーマの選択は保存され、すべてのセッションに適用されます
- **対応言語**: highlight.js の[対応言語の一覧](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)を参照してください
