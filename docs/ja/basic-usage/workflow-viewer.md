# Workflow Viewer

Workflow Viewer は、選択中のアプリの構成をライブ図解します。入力がシステムプロンプトとモデルを経て応答になる流れと、アプリが利用できるツール・エージェント・機能を一望できます。システム設定画面の **Workflow Viewer** コントロールから開きます。

## 表示モード

| モード | ボタン | 動作 |
|------|--------|----------|
| Hidden | 目に斜線のアイコン | ビューアを閉じます。 |
| In Panel | ウィンドウのアイコン | 設定エリア内に図を埋め込み表示します（既定）。 |
| Floating | 矢印が外に出るアイコン | 移動・リサイズ可能なパネルとして開きます。 |

ビューア内のツールバーには、Zoom out、Zoom in、Fit to view、Save as SVG、Close があります。

## 図の読み方

ノードは役割ごとに色分けされ、下部の凡例にカテゴリー（Input/Response、Speech (STT/TTS)、Prompt、Model、Tool、Agent、Feature、Context）が示されます。縦のラインが会話の流れ（入力 → プロンプト → モデル → 応答、音声が有効な場合は音声入出力も）を表し、横のノードがアプリのツール・エージェント・機能・Monadic コンテキストスキーマを表します。

### ツールとスキルグループ

**Tools** ノードには、アプリ固有のツールと共有スキルグループが並びます。グループはクリックで展開・折りたたみできます。

- **🔒（ロック）** — *条件付き*スキルグループ: アプリはこれらのツールに到達できますが、AI が `request_tool` でリクエストした後にのみ提供されます（[ツールグループ](../advanced-topics/tool-groups.md)参照）。
- **🔓（解放済み）** — この会話で既に解放されたグループ。このセッションの残りの間、ツールが利用可能です。
- **✓** — このセッションで解放された個々のツール。

会話の途中で AI がスキルを解放すると、図は自動的に更新されます。チャートは常にセッションの実際の能力セットを反映します。解放済みスキルはセッションのエクスポートに保存され、インポート時に復元されます。

### どのアプリがツールを拡張できるか

アプリごとに、リクエストできるスキルのグループが決まっています（アプリを作る人は[ツールグループ](../advanced-topics/tool-groups.md)を参照してください）。

- **Knowledge Base 検索**（`library_search`）は、ツール対応アプリ（Privacy Filter のあるアプリと、これを切っているアプリを除く）に条件付きスキルとして自動追加され、Knowledge Base パネルの **Use Knowledge Base for retrieval (this session)** がオンの間は、`request_tool` での要求なしに AI に提示されます（既定はオフ）。

Tools ノードにまったく表示されないスキルグループは、そのアプリでは獲得できません — AI にリクエストを頼んでも成功しません。
